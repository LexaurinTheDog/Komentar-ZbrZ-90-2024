# Komentář k zákonu č. 90/2024 Sb., o zbraních a střelivu

Odborný komentář k **zákonu č. 90/2024 Sb., o zbraních a střelivu (ZbrZ)** — novému zbraňovému kodexu, který nahradil zákon č. 119/2002 Sb.: kategorie zbraní R1–R4/PO/NO a střeliva S1–S4, dvoustupňový systém zbrojních oprávnění a licencí, centrální registr zbraní, střelnice, munice a dozor Policie ČR. Nový zákon — judikatura k němu dosud neexistuje.

Konsolidované znění: dokument e-Sbírky `SB-2024-00090_2026-01-01`.
